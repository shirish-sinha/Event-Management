# Event Management

## Introduction

This project is a beginner-level GitHub collaboration project designed to demonstrate how a team can work together using Git and GitHub.

The project represents an Event Management Team where each member has a specific responsibility.

## Team Roles

| Member | Role | Main Responsibility |
|--------|------|---------------------|
| Member 1 | Treasurer | Handles the event budget and finances |
| Member 2 | Manager | Manages the overall event |
| Member 3 | Co-ordinator | Coordinates people, activities and schedules |
| Member 4 | Designer | Handles the visual design and creative work |

## Project Objective

The objective of this project is to understand:

- Git and GitHub basics
- Creating and managing branches
- Working collaboratively in a team
- Creating Markdown (`.md`) files
- Making commits
- Pushing changes to GitHub
- Creating Pull Requests
- Merging branches into the main branch
